# Research skills for Codly agents

Skills (Claude Code / Codex `SKILL.md` format) that make a Codly agent a better AI safety research
assistant: `challenge-idea`, `design-experiment`, `lit-review`, `pre-mortem`.

Install them for every agent on this machine (Claude Code and Codex user scope):

    research-skills/install.sh

An agent uses one when asked by name ("use the pre-mortem skill on this plan") or when the request
matches its description. The voice knows their names and asks for them when they fit.
